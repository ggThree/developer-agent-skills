# 示例目录

本目录展示 Skill 在真实工程语境中的输入、证据、判断与输出边界。所有仓库名、分支、提交和代码均为虚构，不包含可用凭据。

| 示例 | 重点 |
| --- | --- |
| [安全提交会话](safe-commit-session.md) | 工作区与暂存区两阶段审查，commit/push 分开确认 |
| [Objective-C Diff 审查](review-objective-c.md) | 生命周期、线程、内存与回归范围 |
| [发布被阻断](release-blocked.md) | 发布门禁、阻断证据和恢复步骤 |

示例只描述 Agent 应有的行为，不代表授权在当前仓库执行命令。
